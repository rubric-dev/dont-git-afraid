# 충돌 해결 가이드

충돌이 발생하면 바이브코더가 가장 당황하는 순간. 차분하고 단계적으로 안내하세요.

## 충돌 발생 시 전체 안내 흐름

```
💥 충돌이 발생했어요! 하지만 걱정 마세요, 같이 해결해봐요.

충돌이 뭐냐면:
같은 파일의 같은 부분을 두 곳에서 수정해서,
Git이 "어느 쪽을 쓸까요?" 하고 물어보는 거예요.
정상적인 상황이고, 해결할 수 있어요!

═══════════════════════════════════════
충돌 파일 목록
═══════════════════════════════════════

   💥 src/Header.tsx
   💥 src/styles.css

📌 해결 방법 (하나씩 해봐요):
```

## STEP 1 — 충돌 표시 이해하기

```
📌 STEP 1 — 충돌 표시 읽는 법

파일을 열면 이런 표시가 있어요:

   <<<<<<< HEAD
   (내가 수정한 코드)
   =======
   (클라우드/다른 사람이 수정한 코드)
   >>>>>>> main

   ↑ 이 부분이 충돌 지점이에요

   <<<<<<< HEAD    ← 여기부터 내 코드
   내 코드 내용
   =======         ← 경계선
   상대방 코드 내용
   >>>>>>> main    ← 여기까지 상대방 코드
```

## STEP 2 — 코드 선택하기

```
📌 STEP 2 — 어떤 코드를 쓸지 고르기

선택지 3가지:
   1️⃣ 내 코드만 쓴다 → <<<<<<< 부터 ======= 사이만 남기기
   2️⃣ 상대방 코드만 쓴다 → ======= 부터 >>>>>>> 사이만 남기기
   3️⃣ 둘 다 합친다 → 두 코드를 적절히 조합

⚠️ 중요: <<<<<<<, =======, >>>>>>> 표시는 반드시 지워야 해요!
   이 표시가 남아있으면 코드가 작동하지 않아요.
```

## STEP 3 — 해결 완료

```
📌 STEP 3 — 해결 완료 처리

충돌을 다 고쳤으면 세이브 포인트를 만들어주세요.
"세이브해줘" 또는 "저장해줘"라고 말하면 돼요.

저도 도와드릴 수 있어요:
   "두 코드 다 보여줘" — 어떤 차이가 있는지 설명해드려요
   "내 코드로 해줘" — 내 버전으로 통일
   "상대방 코드로 해줘" — 상대방 버전으로 통일
   "합쳐줘" — 두 변경사항을 합치는 걸 도와드려요
```

## 충돌 해결 취소하기

```
↩️ 충돌 해결을 취소하고 합치기 전 상태로 돌아갈까요?

합치기 시도 자체를 취소해서,
충돌이 발생하기 전 상태로 되돌아가요.
수정했던 내용은 사라지지 않아요.

🟢 안전  [█░░░]
```
