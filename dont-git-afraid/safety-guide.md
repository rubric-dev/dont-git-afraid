# 안전 & 긴급 구조 가이드

## .gitignore — 무시 목록 관리

### .gitignore가 없을 때 자동 안내

프로젝트에 `.gitignore` 파일이 없으면, 첫 세이브 전에 반드시 안내:

```
⚠️ 잠깐! 무시 목록(.gitignore)이 없어요!

이게 없으면 올리면 안 되는 파일까지 세이브돼요.
예를 들면:
   📦 node_modules/ — 설치 파일 수만 개 (절대 올리면 안 됨!)
   🔑 .env — 비밀번호, API 키 (올리면 보안 사고!)
   📁 .next/, dist/ — 빌드 결과물 (올릴 필요 없음)

무시 목록을 만들어드릴까요?
```

### 무시 목록 자동 생성

```
✅ 무시 목록을 만들었어요!

무시되는 것들:
   📦 node_modules/ — 설치 파일 (npm install로 다시 받을 수 있음)
   🔑 .env, .env.local — 비밀번호, API 키
   📁 .next/, dist/, build/ — 빌드 결과물
   📁 .DS_Store — Mac 시스템 파일
   📁 .vscode/ — 에디터 설정

이 파일들은 세이브할 때 자동으로 무시돼요.
```

### .env 파일 경고

세이브할 파일 중에 `.env`나 비밀번호가 포함된 파일이 있으면 반드시 경고:

```
🚨🚨🚨 보안 경고 🚨🚨🚨

.env 파일이 세이브 목록에 있어요!
이 파일에는 비밀번호나 API 키가 들어있을 수 있어요.

GitHub에 올라가면 전 세계 누구나 볼 수 있어요!
해커봇이 24시간 GitHub을 감시하고 있어요!

🔴 위험  [████]

.gitignore에 .env를 추가해서 무시 목록에 넣을까요?
```

## 패닉 상황 대응

### "아무것도 안 했는데 빨간 글씨가 떴어요"

```
😌 빨간 글씨가 떴다고 해서 다 위험한 건 아니에요!

가장 흔한 원인:
   📝 수정한 파일이 있는데 세이브 안 해서 → 세이브하면 해결
   ⬇️ 클라우드에 새 버전이 있어서 → 다운로드하면 해결
   🌿 다른 평행 세계에서 작업 중이어서 → 정상 상황
```

### "코드가 다 날아갔어요!" (패닉 상황)

```
😰 진정하세요! 거의 대부분 복구할 수 있어요.

코드가 사라지는 경우:
   1️⃣ 세이브 안 하고 평행 세계 이동 → 원래 세계로 돌아가면 있어요
   2️⃣ reset --hard 실행 → reflog에서 복구 가능
   3️⃣ 파일을 직접 삭제 → 마지막 세이브 포인트에서 복구 가능
   4️⃣ 임시 서랍에 넣음 → 서랍에서 꺼내면 돼요

지금 상태를 분석해서 복구 방법을 안내해드릴게요.
```

### "GitHub에 이상한 파일이 올라갔어요" (node_modules, .env 등)

```
😱 올리면 안 되는 파일이 올라갔어요!

📦 node_modules가 올라간 경우:
   1. 무시 목록에 node_modules/ 추가
   2. 추적 해제 (git rm -r --cached node_modules)
   3. 세이브 + 업로드

🔑 .env 파일이 올라간 경우:
   1. ⚠️ 즉시 해당 API 키/비밀번호를 변경하세요!
      (이미 노출됐을 수 있어요)
   2. 무시 목록에 .env 추가
   3. 추적 해제
   4. 세이브 + 업로드

이 과정을 제가 도와드릴게요.
```
